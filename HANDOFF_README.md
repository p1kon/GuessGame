# Как перенести «Угадайку» в Codex без потери существенного контекста

Это комплект от 2026-11-13, подготовленный по обсуждению проекта в ChatGPT и фактической документации релиза v2.3.2. **Это не буквальная стенограмма всего чата.** Для полного архива беседы отдельно экспортируйте историю ChatGPT через Settings → Data controls → Export data и сохраните ZIP приватно. Не загружайте туда автоматически всю личную историю в публичный GitHub.

## Содержимое
- `AGENTS.md` — краткие устойчивые инструкции для Codex: инварианты алгоритмов, регрессионная дисциплина, требования к данным.
- `PROJECT_CONTEXT.md` — цели, эволюция проекта, научные и психологические гипотезы, результаты и решения, которые неочевидны из кода.
- `DESIGN_TELEGRAM.md` — предложение схемы многопользовательской игры и БД, пока НЕ утверждено.
- `ROADMAP.md` — рекомендуемые этапы.
- `CODEX_FIRST_PROMPT.md` — безопасная первая задача Codex (анализ без изменений).
- `reference/` — неизменённые копии v2.3.2 и документации для справки. Сверить их с реальным содержимым репозитория; не перезаписывать более новые коммиты!

## Подключение
1. Сделайте backup и проверьте, что в GitHub реально закоммичены актуальная v2.3.2 и документация. Если код на GitHub новее, не считать этот комплект истиной без сравнения.
2. Скопируйте новые `.md` в корень репозитория. Копии `reference/` лучше положить в отдельную архивную папку/ветку или оставить локально, если в основном репо уже есть актуальный код.
3. Создайте отдельный commit и ветку для следующего этапа. Подключите репозиторий в Codex Cloud либо откройте локальный repo через Codex CLI/IDE.
4. В новом разговоре Codex отправьте содержимое `CODEX_FIRST_PROMPT.md`.
5. Сначала утвердите предложенный план. Затем выполняйте фазы по отдельным задачам и pull request, с тестами и пояснениями.

## Границы приватности
Не помещайте в общедоступный репозиторий исходную личную историю реальных ходов, экспорт всей переписки ChatGPT, Telegram ID, персональные данные добровольцев, API-токены и `.env`. Реальные истории нужны в тестах — использовать локальные/приватные fixtures либо обезличенные синтетические наборы с отдельным сравнением в безопасной среде.

## Что не следует пытаться сделать автоматически
Нельзя считать, что отдельная задача Codex сама по себе получила всю историю этого ChatGPT-чата. `AGENTS.md` и файлы контекста помогают перенести устойчивые решения; экспорт чата остаётся первоисточником для деталей и нюансов. При принципиальном изменении гипотез фиксируйте решение в `PROJECT_CONTEXT.md`/ADR и создавайте новую ревизию.
