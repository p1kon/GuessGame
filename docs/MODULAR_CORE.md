# Модульное ядро: этап 1

Дата: 2026-11-14. Статус: предварительная сборка `modular-preview-1`, не новый исследовательский релиз. Алгоритм и формат экспортов сохраняют версию 2.3.2 для прямого сравнения. Замороженные релизные файлы не изменены.

## Структура

| Файл | Ответственность |
|---|---|
| `src/core/predictor.mjs` | 16 экспертов, PPM/CTW/SGD, сессии, сериализация, replay, четыре агрегатора, PredictorEngine |
| `src/core/virtual-player.mjs` | Детерминированный ИНР v0.2; импортирует проверку бита |
| `src/core/simulation.mjs` | Симуляция, метрики и сценарии; зависит от предсказателя и ИНР |
| `src/core/index.mjs` | Публичная точка импорта ядра |
| `src/browser/app.js` | Ручное состояние, localStorage, импорт/экспорт, DOM и интерфейс лаборатории |
| `src/browser/template.html` | Разметка и стили с местом для встроенного скрипта |
| `scripts/build.cjs` | Детерминированная сборка автономного HTML без зависимостей |

Пример Node.js:

```js
import { PredictorEngine, restoreState } from './src/core/index.mjs';
const engine = new PredictorEngine();
const snapshot = engine.predict(1700000000000, false);
// В будущем сервере snapshot нужно сначала надёжно сохранить.
engine.update(1, snapshot, { answeredAt: 1700000001000, source: 'simulated' });
const restored = new PredictorEngine(restoreState(engine.exportState()));
```

Время и источник передаёт вызывающая сторона. Движок не выполняет транзакции, авторизацию или дедупликацию сетевых запросов. Проверка устаревшего snapshot не заменяет GameService. `serializable` теперь требует явное состояние. Хранение экспериментальных агрегаторов сохраняет прежние ограничения; это не новый серверный формат снимков.

## Сборка и проверки

```powershell
npm run build
npm test
npm run test:equivalence
```

Результат: `dist/GuessGame_next.html` и SHA-256 в `dist/checksums.json`. Сборка не использует время, сеть или пакеты. Повторный запуск даёт одинаковые байты. `dist/` игнорируется Git. HTML открывается с диска без сервера: сборщик удаляет однострочные импорты и списки экспортов из фиксированного списка модулей, затем встраивает их тела и клиентский код. При изменении синтаксиса связей нужно обновить сборщик и тесты.

`test:equivalence` теперь сравнивает эталон с новой сборкой. В публичной CI используется синтетическая история. Приватная проверка:

```powershell
$env:GUESSGAME_PRIVATE_STATE = 'C:\path\to\private-state.json'
npm test
node verify_equivalence.js GuessGame_v2.3.2.html dist/GuessGame_next.html $env:GUESSGAME_PRIVATE_STATE
```

Проверка реального браузера:

```powershell
$env:BROWSER_EXECUTABLE = 'C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe'
npm run test:browser
```

Браузер работает в headless-режиме с временным профилем и искусственными данными. Проверяются ручной ход, отказ записи, продолжение в RAM, отмена сброса при ошибке, повторное сохранение, успешный сброс и 60 ходов лаборатории. Внешний вид и полный набор сценариев импорта/экспорта этим не покрываются.

## Протокол отличий и результаты

Ожидается: неизменные математические результаты и сериализация; новая структура исходников и отдельный автономный артефакт. Глобальное браузерное состояние и зависимая от него диагностика перенесены в клиент. Неиспользуемая функция `initWeights`, обращавшаяся к глобальному state, исключена. Формулы и порядок обновлений сохранены.

В новой разметке отсутствует внешний скрипт Kaspersky, вставленный в репозиторный эталон. Старая версия сохранена побайтово. Исключение внешнего скрипта делает новую сборку автономной; остальная разметка и стили сохранены.

Факт: полные прогнозы, вероятности, признаки, сериализованное состояние и эффективные веса совпадают на 220 ходах каждого агрегатора с границами сессий. Четыре 600-ходовые симуляции со сменами G совпадают по журналам и экспортам. Семь сценариев сравнения HTML прошли на синтетической и реальной историях. Подтверждены 1200/758 и контрольные 413/600. Edge smoke прошёл. Автотест проверяет неизменность исходных релизных файлов и детерминированность сборки.
