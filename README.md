# GuessGame

Исходный код распространяется под [лицензией MIT](LICENSE). Пользовательские истории, приватные экспорты, базы данных и секреты в опубликованный проект не входят.

Исследовательская игра: персональное предсказание двоичных решений и адаптация к меняющемуся поведению игрока.

Замороженный выпуск — `GuessGame_v2.3.2.html`. Открывается непосредственно в браузере. Его алгоритмы и содержимое сохранены; описание выпуска — в `README_v2.3.2.md`, полная документация — в `CODE_DOCUMENTATION_v2.3.2.md`.

## Подготовка следующей версии

Контекст: `PROJECT_CONTEXT.md`. Последовательность этапов: `ROADMAP.md`. `DESIGN_TELEGRAM.md` содержит предложения, детали сервера и публичного пилота ещё требуют решений. Выделено общее вычислительное ядро без изменения алгоритмов. Структура, API и протокол проверки — в [docs/MODULAR_CORE.md](docs/MODULAR_CORE.md).

Нужен Node.js 22.13 или новее. Внешние зависимости отсутствуют.

Локальный GameService с SQLite, отдельными игроками и транзакционными ходами: [docs/GAME_SERVICE.md](docs/GAME_SERVICE.md). Демонстрация на искусственных данных: `npm.cmd run demo:service`.

Закрытый Telegram-адаптер: [настройка и запуск](docs/TELEGRAM.md). Заполните локальный `.env`, затем `npm.cmd run telegram:check` и `npm.cmd run telegram:start`. Владелец проверил личную игру и сохранение между перезапусками; публичное размещение не выполнялось.

Прежнюю личную историю можно перенести в существующего Telegram-игрока с сохранением уже сделанных ходов: [протокол импорта](docs/HISTORY_IMPORT.md).

Рабочий бот перенесён на VPS с автозапуском и ежедневными копиями. [Управление сервером и восстановление](docs/DEPLOYMENT.md). Локальный экземпляр с тем же токеном должен оставаться выключенным.

Многопользовательская веб-версия с логином/паролем и подтверждаемой привязкой Telegram: [описание и инструкция](docs/WEB_ACCOUNTS.md). Если уже играли в боте, сначала привяжите Telegram и только потом делайте веб-ходы.

```powershell
npm run build
npm test
npm run test:equivalence
```

Сборка создаёт автономный `dist/GuessGame_next.html` и файл контрольных сумм. Тесты проверяют 413/600, восстановление, безопасность хранения и совпадение нативных модулей с эталоном. `test:equivalence` сравнивает замороженный HTML с новой сборкой на синтетической истории. Для других версий:

```powershell
node verify_equivalence.js old.html new.html
```

Приватная регрессия запускается локально с внешним файлом:

```powershell
$env:GUESSGAME_PRIVATE_STATE = 'C:\path\to\private-state.json'
npm test
node verify_equivalence.js old.html new.html $env:GUESSGAME_PRIVATE_STATE
```

Исторический тест ожидает 1200/758. Этот JSON не входит в репозиторий или CI. Синтетические данные отмечены `source: simulated`; они не являются наблюдениями за человеком. Не публикуйте личные истории, токены, базы и экспорты. Рабочие приватные файлы можно хранить в игнорируемом `private/`.

Результаты исходного аудита и ограничения: `baseline/REPORT.md`. Контрольные суммы неизменяемых артефактов: `baseline/checksums.json`.
